Description:

This project implements the visualization of a laptop webcam feed using OpenCV. 
It also includes a function to switch the image color from RGB to grayscale by pressing "d" once.

How to download:

1. Download the zip-file.
2. Open it.
3. Download python and install it on your computer.
4. Run main.py.
